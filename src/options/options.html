Claude Usage Monitor — Settings

Alert threshold

Discord alerts

Server Settings → Integrations → Webhooks → New Webhook → Copy URL. Leave blank to disable.

Telegram alerts

Message @BotFather on Telegram → /newbot → copy the token. Then message your new bot once, and visit https://api.telegram.org/bot<TOKEN>/getUpdates in a browser to find your chat ID in the response. Leave blank to disable.

Slack alerts

Slack app settings → Incoming Webhooks → Add New Webhook to Workspace → Copy URL. Leave blank to disable.

Self-hosted dashboard

Address of your own backend/ server (see the repo's backend/README.md). Saving this will prompt Chrome to ask permission to reach that address — needed since the extension talks to it directly. Leave blank to disable.
