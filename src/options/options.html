Usage Monitor for Claude(Unofficial) — Settings

Set up how and when you'd like to hear about your usage.

Alert Thresholds

Add as many percentage checkpoints as you'd like, you'll get pinged every time usage climbs past one, tracked separately for each limit (session, weekly, and so on).

Slack Alerts

Want a heads-up in Slack when a limit gets close? Here's how to connect it:

  1. In Slack, open your app settings and go to Incoming Webhooks.
  2. Click Add New Webhook to Workspace and pick a channel.
  3. Copy the webhook URL Slack gives you and paste it below.
Leave this blank if you'd rather not use Slack.

Discord Alerts

Prefer Discord? It's just as quick from your server settings:

  1. Open Server Settings → Integrations → Webhooks.
  2. Click New Webhook and name it whatever you like.
  3. Copy the webhook URL and drop it in below.
Leave this blank if you'd rather not use Discord.

Telegram Alerts

Telegram takes one extra step since it needs both a bot and a chat ID:

  1. Message @BotFather on Telegram, send /newbot, and copy the token it gives you.
  2. Send your new bot any message, then visit https://api.telegram.org/bot<TOKEN>/getUpdates in a browser.
  3. Find your chat ID in that response and paste both values in below.
Leave both blank if you'd rather not use Telegram.

Self-hosted Dashboard

Running your own dashboard at home? Point the extension at it to keep a history there too:

  1. Get the backend/ server running (see backend/README.md in the repo).
  2. Enter its address below, e.g. http://192.168.1.50:3000.
  3. Saving will prompt Chrome to ask permission for that address — that's expected, just approve it.
Leave this blank if you don't have one set up.
